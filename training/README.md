# Обучение сети распознавания дефектов

Здесь лежит всё, чтобы обучить сеть из ВКР и получить файл `model.onnx` — его потом запускает Web API.
Обучение рассчитано на компьютер с видеокартой NVIDIA (RTX 5070).

Результат обучения — два файла в этой папке:

- `model.onnx` — обученная сеть;
- `metrics.json` — показатели качества на тестовой выборке.

## Что нужно на компьютере

- Windows, видеокарта NVIDIA со свежим драйвером.
- Python 3.12, 3.13 или 3.14 с сайта python.org. При установке поставить галочку **Add python.exe to PATH**.
- Около 10 ГБ свободного места и интернет: скачиваются библиотеки (около 3 ГБ) и снимки (около 1 ГБ).

## Порядок действий

Все команды выполняются в **командной строке, открытой в папке `training`**.
Открыть её так: зайти в папку `training` в Проводнике, щёлкнуть по адресной строке, набрать `cmd` и нажать Enter.

### 1. Создать отдельное окружение для библиотек

```
python -m venv .venv
.venv\Scripts\activate
```

После второй команды в начале строки появится `(.venv)`. Библиотеки будут ставиться в папку `.venv`,
а не в систему. Если командная строка закрыта и открыта заново — команду `.venv\Scripts\activate` нужно повторить.

### 2. Установить библиотеки

```
pip install torch==2.14.1 torchvision==0.29.1 --index-url https://download.pytorch.org/whl/cu130
pip install -r requirements.txt
```

Первая команда ставит PyTorch в сборке под видеокарты NVIDIA (в том числе 50-й серии), она скачивает около 3 ГБ.

### 3. Проверить, что PyTorch видит видеокарту

```
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

Должно вывести `True` и название видеокарты. Если вывело `False` или ошибку — см. раздел «Если что-то пошло не так».

### 4. Скачать снимки и собрать датасет

```
python download_datasets.py
python prepare_dataset.py
```

Первая команда скачивает три открытых набора снимков (NEU, GC10, X-SDD), вторая собирает из них
единый датасет из 10 классов в папке `dataset`. В конце вторая команда печатает таблицу: всего должно быть 5320 снимков.

### 5. Быстрая проверка

```
python train.py --smoke
```

Занимает пару минут: берётся малая часть снимков и делается два шага обучения. В первой строке должно быть
`Устройство: видеокарта ...`, в конце — `Готово`. Числа качества в этом режиме ничего не значат, проверяется только то, что всё запускается.

### 6. Обучение

```
python train.py
```

Идёт 30 эпох. После каждой эпохи скрипт пишет, сколько времени прошло и сколько примерно осталось.
Компьютер в это время лучше не выключать и не переводить в сон. В конце скрипт сам:

- проверяет сеть на тестовой выборке и печатает показатели (Recall@1 и другие);
- сохраняет `model.onnx` и `metrics.json` в папку `training`.

## Как передать результат на основной компьютер

В GitHub Desktop появятся два новых файла: `training/model.onnx` и `training/metrics.json`.
Их нужно закоммитить и отправить (Commit, затем Push), а на основном компьютере — получить (Fetch, затем Pull).

## Если что-то пошло не так

- **Шаг 3 выводит `False`.** Обновить драйвер видеокарты NVIDIA и повторить шаг 3. Если не помогло — проверить,
  что PyTorch ставился именно командой из шага 2 (с адресом `.../whl/cu130`).
- **`python` не является внутренней или внешней командой.** Python установлен без галочки «Add python.exe to PATH» — переустановить с ней.
- **Ошибка `CUDA out of memory`.** Закрыть игры и другие программы, занимающие видеопамять, и запустить обучение снова.
- **Обучение прервалось.** Запустить `python train.py` заново — оно начнётся с начала.
- **Предупреждение про `HF_TOKEN` или `unauthenticated requests`.** Это не ошибка: так сообщает о себе сайт, с которого скачиваются начальные веса сети.
